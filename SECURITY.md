# Security

This project is a prototype. Pair only with a gateway you control and provision credentials at runtime. Treat firmware binaries/NVS dumps and device logs as potentially sensitive. Do not expose the device or provisioning interface directly to the public internet.

Do not open a public issue containing a token, Wi-Fi credential, device identity, raw gateway response, personal calendar, or message. For suspected vulnerabilities, use the repository's private vulnerability-reporting feature if enabled. If private reporting is unavailable, open a minimal issue requesting a private contact **without exploit details or personal data**. No dedicated security inbox or response SLA is currently promised.

If a credential has been published, revoke/rotate it before cleaning source or history. An ignore rule does not remove data already committed.
